# 01 — PILLARS, STANDING INSTRUCTION & TOPIC QUEUE

> **Fill this in once per project.** Update the standing instruction whenever
> the analytics contradict it — with the evidence and the date.

## 1. Pillars

Aim for **3–8**. Fewer is sharper. Each pillar must be:
distinct (not a sub-type of another), ownable (you could be known for it), and
repeatable (30+ posts, not 3).

| # | Pillar | What it covers | Tone | Share |
|---|---|---|---|---|
| 1 | | | | |
| 2 | | | | |
| 3 | | | | |
| 4 | | | | |
| 5 | | | | |

Rules:

- Every post belongs to exactly one pillar.
- Never two consecutive posts in the same pillar (unless the sub-type differs).
- The share column is a target, not a quota — the standing instruction wins.

## 2. Standing instruction (data-driven mix)

**Copy this block and keep it current. It is an instruction, not a memory.**

```
STANDING INSTRUCTION (last updated: ____-__-__)
__% [pillar/subject] / __% [pillar/subject].
Evidence: [the test, the numbers, the date].
Applies to: all new posts unless explicitly overridden.
Notes: [what to prioritise *within* the bigger share — e.g. "alien biology"
over general facts].
```

### Worked example (BioLens)

```
STANDING INSTRUCTION (last updated: 2026-07-01)
70% Animal / Insect / Plant / Microbe / 30% Human Anatomy.
Evidence: controlled A/B by topic, July 2026 — animal biology outperformed
human anatomy on views and retention; not a hook-quality gap, a genuine topic
preference.
Applies to: all new posts unless explicitly overridden.
Notes: within the 70%, prefer "alien biology" (impossible-sounding mechanisms)
over general animal facts. Within the 30%, prefer hidden or impossible human
processes over familiar facts, even when the familiar fact has a big number.
```

## 3. Rotation rules

| Rule | Why |
|---|---|
| No two consecutive posts in the same INTERRUPT category | The audience adapts to a repeated trick within days |
| No two consecutive posts in the same pillar | Prevents the feed reading as "one topic" |
| At least 4 different categories per week | Keeps the catalogue visually varied |
| Never two salesy posts in a row | Protects trust |
| One proof post per ~5 posts | Proof earns the right to sell |
