# 04 — CAPTIONS, HASHTAGS & PINNED COMMENTS

> Fill the templates once per project. Then every post reuses the structure and
> only the hook line and body change.

---

## 1. Caption rules

1. **The first line is the hook.** Same punch as the on-screen text, rewritten
   for the platform. Never start with context.
2. **Short lines.** One idea per line. Line breaks are pacing.
3. **No hashtags in the middle of a sentence.** Either end of caption or first
   comment — pick one and stay consistent.
4. **The link goes in the bio on Instagram/TikTok**, and in the caption on
   YouTube/Facebook.
5. **One CTA.** Not "follow, like, share and comment".
6. **The caption must still work if the video never plays.**

---

## 2. Caption templates

### TikTok / Instagram Reels
```
[HOOK — the impossible line, verbatim from the video]

[One line of stakes or context.]

[One line of the mechanism or the reveal.]

[CTA]. Link in bio.
```

### YouTube Shorts (searchable)
```
[HOOK] — [what the video actually explains, in search keywords].

[2–3 sentences expanding the mechanism, written for search.]

Free guide / next step in the description.
```

### Facebook
```
[HOOK]

[2–3 sentences, more complete sentences — Facebook rewards reading.]

[Question to the audience.]

[CTA]
```

### X / Threads
```
[HOOK]

[One sentence of mechanism.]

[CTA]
```

### Long caption (LinkedIn / YouTube community)
```
[HOOK]

[Paragraph: the story or the problem.]
[Paragraph: the mechanism.]
[Paragraph: what to do about it.]

[CTA]
```

**Short-form companion format (GHL, ≤300 characters)** — for tools that cap the
caption:
```
[Hook sentence.] [Mechanism in 2–3 fragments.] [Payoff line.] #tag1 #tag2 #brand
```

## 3. Hashtag strategy

Use **8–12** per post. Three tiers, every time:

| Tier | Purpose | Examples |
|---|---|---|
| **Reach** (high volume) | Discovery | `#aivideo` `#viralvideo` `#shorts` |
| **Creator / buyer** (your audience) | The people you want | `#contentcreator` `#biology` |
| **Niche** (low competition, on-brand) | Identity + algorithm topic | `#scrollstopper` `#patterninterrupt` |

Rules:

- Keep the same core set so the algorithm learns the topic.
- Rotate 2–3 reach tags per post to test.
- Never use a hashtag the content does not earn.

**Project hashtag set:**

```
REACH:
CREATOR:
NICHE:
BRAND:
```

## 4. Pinned comments

Every post gets one pinned comment, written before publishing. Its job is to
start the thread, not to summarise the post.

Patterns that work:

- **The receipt:** "Unedited screenshots are on the landing page if you want to
  verify before believing it — link in bio."
- **The usefulness:** "The exact prompt is in the free guide. Takes 2 minutes."
- **The stake:** "If your retention drops in the first 2 seconds, this is the
  fix. It's free."
- **The invitation:** "Tell me the one that stopped YOUR scroll this week."

**Do not** pin "Thanks for watching" or anything that ends the conversation.

---

## 5. Comment seeding (three per post)

Each post ships with three comments in `03_POST_BANK.md`. They must be:

1. **Specific** — about this post, not any post.
2. **Answerable** — a viewer can reply in five words.
3. **Non-promotional** — they invite, they do not sell.

Weak → strong:

| Weak | Strong |
|---|---|
| "Great video!" | "Did you notice there were no walls?" |
| "Thoughts?" | "What warning sign do adults notice too late?" |
| "Follow for more" | "Which of the three triggers do you use most?" |

---

## 6. Publishing rhythm

- Match cadence to `00_DNA.md`.
- Strongest post of the week goes out first.
- Stagger shorts from the same research across the week.
- Never two salesy posts back to back.
- Post, then pin the comment immediately.
- Reply to every comment for the first 90 days.

## 7. Caption checklist

- [ ] First line is the hook
- [ ] Body adds something the video did not say
- [ ] Works with the video muted and unwatched
- [ ] 8–12 hashtags across the three tiers
- [ ] Link placement correct for the platform
- [ ] One CTA
- [ ] Pinned comment written and ready
